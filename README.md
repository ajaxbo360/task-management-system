# Task Management System

Full-stack task management application with team collaboration features.

## 🛠 Tech Stack

**Backend:**

- Node.js + Express
- TypeScript
- MongoDB + Mongoose
- JWT Authentication

**Frontend:**

- React 18
- TypeScript
- Vite
- Material UI
- Redux Toolkit
- React Router

## 🚀 Getting Started

### Prerequisites

- Node.js (v18+)
- MongoDB
- npm or yarn

### Backend Setup

```bash
cd backend
npm install
cp .env.example .env
# Edit .env with your MongoDB URI
npm run dev
```

Backend runs on http://localhost:5000

### Frontend Setup

```bash
cd frontend
npm install
cp .env.example .env
npm run dev
```

Frontend runs on http://localhost:5173

## 📁 Project Structure

task-management-system/

└── frontend/ # React app
